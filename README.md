# app-support

Support websites for iPhone apps developed by Amit Khare.

## Structure

- `index.html` — main landing page listing all apps
- `privacy.html` — privacy-policy landing page
- `style.css` — shared site styling
- `apps/yentrack/` — YenTrack support and privacy policy
- `apps/raag-saregama/` — Raag SaReGaMa support, privacy policy, and third-party software attribution

Each app has its own support page and privacy policy so that the
corresponding App Store listing can use an app-specific Privacy Policy URL.

## Raag SaReGaMa

Raag SaReGaMa uses the Synthesis ToolKit in C++ (STK) for audio synthesis.
The app-specific third-party software page contains the required STK
copyright and license notice.
